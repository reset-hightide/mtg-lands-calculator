Base usada para estimar o modelo (decks com mais vitórias que derrotas, MTG Melee, jul/2020 a jul/2022), enriquecida com arquétipo e número de cores. Fonte original: Frank Karsten, Kaggle.

Colunas: lands = terrenos puros; lands_mdfc = terrenos + MDFC ponderados (0,38 não míticos / 0,74 míticos), variável-resposta do modelo; cheap_draw / cheap_ramp = compra/aceleração barata (CMC ≤ 2), regras do Karsten.

Os registros apontam para páginas públicas do MTG Melee; nomes de jogadores não foram incluídos.
